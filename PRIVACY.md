# Privacy Policy for Network Recorder

_Last updated: 20 November_

Network Recorder is a Chrome extension that records the network requests and responses of the user's open tabs so the user can review them later.

## Data the extension handles

To do this, the extension reads network traffic from the tabs you have open. This can include URLs, request and response headers, cookies, authentication tokens, request and response bodies, and WebSocket messages. It can therefore include personal or sensitive information, depending on the websites you visit.

## Where the data goes

All captured data is stored locally in your browser (in IndexedDB). The extension does not send this data anywhere. It does not transmit, sell, share, or transfer it to any server or third party. It contains no analytics, advertising, or tracking code, and it does not load remote code.

## Your control

You can pause recording at any time. You can delete all captured data with the "Clear" button in the viewer. Removing the extension also removes its stored data. The "Export JSON" button saves a file to your own computer. What you do with that file is up to you.

## Permissions

- `debugger`: reads network requests and responses from tabs.
- `tabs`: detects open tabs and navigation so recording can attach to them.
- `storage`: saves the pause/resume setting.
- `unlimitedStorage`: stores captured data locally.
